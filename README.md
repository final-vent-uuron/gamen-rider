# gamen-rider

仮面ライダー龍騎モチーフの **IoT 対戦ゲーム**。
カードデッキをかざして「変身」し、自分が認証したライダーの姿になって対戦する。
パンチ・キック・移動は身体の動き（加速度センサー）で行い、必殺技「ファイナルベント」はカード＋ポーズで撃つ。

ハッカソン作品。

---

## どんなゲーム？

- **対戦形式**：個人戦 1v1v1v1（4人）
- **構成**：2台の PC に各2人ずつ。4人が同じアリーナで戦う
- **見た目**：横スクロール系の 3D 対戦。スマブラ風（HP制 / スマブラ風UI）
- **目玉**：カード＋ポーズで放つ必殺技「**ファイナルベント**」

---

## 遊びの流れ

1. **画像認証** — 自分のカードデッキをカメラにかざす。ORB 特徴点マッチングでカード（＝ライダー）を識別。
2. **ポーズ認証** — 特定のポーズを取る。カードとポーズの**両方**をクリアすると変身成立。
3. **バトル** — 認証したライダーの姿で対戦開始。
   - 移動：足の加速度センサー
   - パンチ / キック：腕の加速度センサー
   - HP が尽きたら脱落
4. **ファイナルベント（必殺技）** — バトル中、画面右下に常時表示された web カメラに **ファイナルベントのカードをかざし → 特定のポーズ** を取ると発動。

---

## 操作方法

| 操作 | 入力 |
|------|------|
| 移動 | 足の加速度センサー |
| パンチ / キック | 腕の加速度センサー |
| カード認証 | PC の web カメラ |
| ポーズ認証 | PC の web カメラ |
| ファイナルベント | 画面右下の web カメラ（カード＋ポーズ） |

> 認証は web カメラ1台を共有するため、同じ PC の2人は**順番に**行う。
> ファイナルベントは、撃ちたくなった人がその都度発動する運用。
